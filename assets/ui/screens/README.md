# Screen sprites: HUD, win screen, lose screen

Generated by `docs/wiki-images/src/opt_screens.lua` (final section at the end of the file).
Proof sheet with all three screens rebuilt from these files: `docs/art-review/final_screens.png`.
1x reference mocks: `docs/art-options/screens/mock_hud_a.png`, `mock_win_a2.png`, `mock_lose_a2.png`.

All positions below are in the 480x270 logical view, top-left origin, in pixels.
Every sprite has a `.png` and an `.aseprite` (layer "Art"). Strips are horizontal, one tag per frame, with a `.json` in the same format as `assets/ui/button.json`.

Notes on individual files:

- `paper_panel`: the right and bottom margins include a 3 px hard shadow. To get a visible paper area of W x H, draw the nine-patch at W+3 x H+3. The bottom margin also carries the 2 px darker paper edge.
- `hud_panel`: the fill is `#1c1a24` at alpha 184 (72 percent), the 1 px border is opaque `#080808`, the four corner pixels are transparent. Used for the objectives panel, the package tray and the restart hint.
- Ribbons: the title text is baked in. Both share one canvas so they swap in place.
- `star`: the empty fill is light grey, made for the paper panel.
- `leader_dots`: one `#c4bdac` pixel followed by two transparent pixels.

## Text

The mocks use the 5x7 uppercase pixel font defined in `docs/wiki-images/src/hwc.lua`, 1 px between letters, at 1x (7 px tall). No font file is exported in this folder. Text y positions below are the top of the 7 px glyphs.
