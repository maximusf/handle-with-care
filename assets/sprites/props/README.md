# Hotel props

Sprites for the hotel levels. Every file is drawn at 1x on the 32 px tile grid with a transparent background. Floor props stand on the bottom edge of their frame. Wall and ceiling props (paintings, clock, exit sign, chandelier, door hanger) are placed freely.

Each prop has a `.png` (a horizontal strip, one frame per cell), an `.aseprite` source with the same frames and tags on a layer named "Art", and for multi-frame props a `.json` with frame and tag data. Lettered files (`_a` to `_e`) are interchangeable variants of the same prop.

The files are generated by `docs/wiki-images/src/opt_props.lua`. The static A designs (`wet_floor_sign_a`, `cactus_a`, `front_desk_a`, `luggage_door_a`) are drawn by `docs/wiki-images/src/gen_props.lua`.

## Shared conventions

- All four robot vacuums use the same frame order: `patrol` is frames 1 to 4, `bump` is 5 and 6, `stuck` is 7 and 8. Vacuums A, B and C are 40 px wide per frame and D is 48 px wide to fit the knife.
- All four carts have a 4-frame `roll` loop and all four fountains have an 8-frame `flow` loop.
- The luggage doors and the elevator have one frame per state: `closed`, `half`, `open`. Their frames are 64x96, matching the 2x3 tile doors in the hotel tileset.
- Single-frame props carry one tag named `idle`.
- "Intended use" is a design suggestion. No collision or damage behaviour is stored in these files.
